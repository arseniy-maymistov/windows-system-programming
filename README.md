# Windows Security and System Programming

Windows-focused coursework covering Win32 API account administration, Windows services, Task Scheduler, RPC client-server design, and concurrent network services.

## Overview

This repository groups coursework on Windows APIs and operating-system facilities. The reports describe utilities for user/group administration, a configurable Windows service for directory backup, Task Scheduler management, an RPC-based remote file manager with client impersonation, and a distributed information-collection service.

## Topics and Features

- Managing Windows users, groups, SIDs, and privileges through Windows APIs
- A Windows service with configuration-file and command-line options for backups
- Task Scheduler automation through Windows APIs
- RPC and client impersonation concepts
- Concurrent client handling with Win32 I/O completion ports and CryptoAPI-based data encryption, as described in the report
- PowerShell automation for Active Directory tasks

## Technologies

C++, Win32 API, RPC, Windows Services, Task Scheduler, Active Directory, PowerShell, Winsock, I/O completion ports, CryptoAPI, libzip
